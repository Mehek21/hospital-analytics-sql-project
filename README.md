# Hospital Analytics Using SQL

## Project Overview
This SQL project analyzes hospital encounter data to identify trends in patient admissions, payer coverage, treatment costs, procedures, and readmission behavior.

## Business Questions Solved
- Total encounters by year
- Encounter class distribution
- Hospital stay duration
- Zero payer coverage analysis
- Top frequent procedures
- Highest-cost procedures
- Quarterly patient admissions
- Readmission analysis

## Key Insights
- Hospital encounters increased significantly over time.
- Nearly 48.7% of encounters had zero payer coverage.
- Most hospital stays lasted under 24 hours.
- ICU admissions had the highest treatment costs.
